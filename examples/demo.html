How it works

Compute features once, score many times

Training was slow because the same image features were recomputed every epoch; now they're computed once and memory-mapped.

⚡Pay for the expensive step once.The frozen backbone gives the same features every epoch, so cache them and only redo the cheap scoring.
Like a kitchen's mise en placeChefs prep everything once before service and then just grab it. (Where it breaks: our "ingredients" never spoil, so the cache only expires when an image changes.)

⑤ Why this design

🗄Memory-mapped fileSurvives restarts; the OS pages data for us.✗ In-RAM dict: 14 GB, lost on crash
🔑Key = content hashEdited images invalidate themselves.✗ Key = path: silently stale
🗣8-prompt ensembleA panel of judges smooths wording quirks.✗ 16 prompts: no gain, slower
ℹ Limits Only helps while the backbone is frozen; fine-tuning would require rebuilding the cache every epoch.
